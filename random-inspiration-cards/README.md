# Word Spark Cards

A Chrome extension that gently pops up five random English words at a configurable interval.

## Features

- Shows five random words in a polished card on the current page.
- Default interval is 10 minutes.
- Set the interval from the popup or options page.
- Pause and resume reminders.
- Trigger a card immediately from the popup.
- Words include short Chinese meanings.

## Install locally

1. Open `chrome://extensions`.
2. Enable Developer mode.
3. Click Load unpacked.
4. Select this `random-inspiration-cards` folder.

Chrome alarm timing can be delayed slightly by browser sleep, tab suspension, or system power settings.
